# Book Audio Reader Web App

Simple GitHub Pages / iPhone PWA.

Files:
- index.html
- app.js
- style.css
- manifest.json
- service-worker.js
- book-icon.svg

How to use:
1. Upload all files to a GitHub repository.
2. GitHub → Settings → Pages.
3. Deploy from branch → main → /(root) → Save.
4. Open the GitHub Pages link in Safari on iPhone.
5. Safari Share → Add to Home Screen.

Features:
- Upload PDF
- Read extractable PDF text aloud in English
- Play / Pause / Stop
- Previous / Next page
- Reading speed
- English voice selector

Note: scanned/image-only PDFs need OCR.
